# 🎓 Student Placement Selector

## 📌 Project Description

**Student Placement Selector** is a student placement preparation and selection system designed to help students understand their placement eligibility and prepare for job opportunities.

The system can collect student details such as academic performance, skills, programming knowledge, certifications, and other placement-related information. Based on the provided details, it can help identify suitable placement opportunities and guide students in their preparation.

## 🎯 Objectives

* Store and manage student placement details.
* Check student eligibility for placement opportunities.
* Help students identify suitable job roles.
* Provide placement preparation guidance.
* Improve students' technical and aptitude preparation.
* Make the placement selection process easier and more organized.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/kanaveniharshini-hub/project-placement-selector.git
```

### 2. Open the project folder

```bash
cd project-placement-selector
```

### 3. Create virtual environment

```bash
python -m venv .venv
```

### 4. Activate virtual environment

For Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

### 5. Install required packages

```bash
pip install -r requirements.txt
```

## ▶️ Run the Project

Run the Streamlit application using:

```bash
streamlit run app.py
```

The application will open in your browser.
